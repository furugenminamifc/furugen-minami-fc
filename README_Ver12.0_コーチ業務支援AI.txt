古堅南FC AI Coach Ver.12.0
コーチの仕事を本当に支えるAI

Ver.11.0までの機能を維持し、試合後のコーチ業務を1画面で完了できるよう改善しました。

追加機能
・5分コーチワークフロー
・作業チェックリストと進捗表示
・チェック状態を端末へ保存
・コーチ注意アラート
・ポジション未設定チェック
・写真未登録チェック
・出場時間の偏りチェック
・直近試合の出場登録、メモ未入力チェック
・AI試合レポート一式作成
・保護者向けLINE文面作成
・次回練習案作成
・共有用試合要約の自動作成とコピー
・Mac、iPad、iPhone対応
・既存の選手管理、試合入力、評価、MVP、AI Coach機能を維持

追加SQL
Ver.9.0のSQLを実行済みなら、Ver.12.0の追加SQLは不要です。

導入方法
1. ZIPを解凍
2. 中身をGitHubへ上書きアップロード
3. Commit changes
4. GitHub Pages反映後にSafariを再読み込み
5. AI Coach → クイックを開く
