古堅南FC Ver.7.2 選手詳細タブ画面 完全版

今回追加した機能
・選手詳細画面を6つのタブに整理
  1. 基本情報
  2. 試合成績
  3. 成長グラフ
  4. AI分析
  5. コンディション（管理者・コーチのみ）
  6. 保護者情報（管理者・コーチのみ）
・試合ごとの出場時間、得点、アシスト一覧
・1試合平均時間、平均得点、平均アシスト
・直近20試合の成長グラフ
・AI育成評価へワンタップ移動
・選手データのコピー
・疲労度と調子のメーター表示
・保護者情報の非公開表示

Supabaseについて
Ver.7.1のSQLを実行済みであれば、Ver.7.2用の追加SQLはありません。

導入方法
1. このフォルダの中身をGitHubへ上書きアップロード
2. Commit changes
3. GitHub Pagesの反映を1〜3分待つ
4. Safariでアプリを再読み込み
5. 「選手」→「詳細」を開いて各タブを確認

確認項目
・基本情報タブが最初に開く
・試合成績タブに記録が表示される
・成長グラフタブにグラフが表示される
・AI分析ボタンでAI画面へ移動する
・管理者またはコーチだけコンディション、保護者情報を閲覧できる
