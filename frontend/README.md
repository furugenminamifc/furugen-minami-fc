# SOCCER VISION ANALYZER PRO 統合版

## 実装済み
- 動画解析、1コマ送り、再生速度
- チーム成績・試合・選手管理
- シーズン分析
- 手動位置記録
- ヒートマップ、シュートマップ、パスマップ、ロストマップ
- ルールベースAI分析コメント
- ハイライト候補
- コーチ・スタッフ・保護者モード
- PDF印刷
- Excel互換 `.xls` とCSV出力
- JSONバックアップ・復元
- PWA/スマホ/PC対応
- Supabase・AI API接続欄

## 外部設定が必要な機能
以下はこのZIPだけでは完全自動化されません。
- 映像からの選手・ボール自動追跡
- AIによる自動イベント認識
- 実際のクラウド同期と複数人同時編集
- 動画ファイルを切り出して結合するハイライト動画生成
- 本格的なログイン・権限認証

これらはSupabase、動画処理サーバー、AIモデル、FFmpeg等を接続して実装します。

## 起動
ZIPを解凍して `index.html` を開いてください。
公開時はGitHub PagesまたはNetlifyへ全ファイルをアップロードしてください。
