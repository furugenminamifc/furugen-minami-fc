古堅南FC AI Coach Ver.14.0
AIがコーチの仕事を先回りする

追加機能
・今日やるべきことを自動表示
・試合記録、出場、メモ、成長目標、ポジションの未入力確認
・出場機会チェック
・出場時間が少ない選手を自動表示
・試合前チェックリスト
・チェック状態の端末保存
・最近伸びている選手の簡易サマリー
・AI育成公平性レポート
・AI成長分析
・今日のコーチ向け要約
・要約コピー
・要約をAI行動計画へ変換
・Ver.13.0までの全機能を維持

追加SQL
不要です。Ver.9.0のSQLを実行済みであれば、そのまま利用できます。

導入方法
1. ZIPを解凍
2. 中身をGitHubへ上書きアップロード
3. Commit changes
4. GitHub Pages反映後にSafariを再読み込み
5. AI Coach画面のクイックを開く
