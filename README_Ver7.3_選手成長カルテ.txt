古堅南FC Ver.7.3 選手成長カルテ 完全版

追加機能
・成長グラフタブを「成長カルテ」に強化
・身長、体重、睡眠時間の記録
・疲労度、調子、ケガ状態の記録
・練習参加、一部参加、見学・休養、欠席の記録
・コーチ評価（5段階）
・記録メモ
・身体成長グラフ
・記録履歴と削除
・最近の成長記録をAI育成評価へ反映

プライバシー
身体・体調・ケガ・睡眠に関する情報は、管理者・コーチのみ閲覧・編集できます。

導入順
1. Supabase SQL Editorで「Ver7.3_選手成長カルテ追加設定.sql」を1回実行
2. このフォルダの中身をGitHubへ上書きアップロード
3. Commit changes
4. GitHub Pages反映後にSafariを再読み込み
5. 選手→詳細→成長カルテで確認

動作確認
・「記録を追加」から保存できる
・身長と体重のグラフが表示される
・記録履歴が表示される
・AI分析に最近の成長記録が含まれる
