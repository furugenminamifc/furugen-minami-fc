古堅南FC Ver.9.1 試合画面評価入力版 完全版

Ver.9.0の機能に加えて、試合入力・編集画面から直接、選手評価を入力できます。

追加内容
・出場チェックを付けた選手だけ評価欄を表示
・攻撃、守備、パス、ドリブル、シュート、判断力、運動量、声かけを5段階評価
・良かったところ
・改善したいところ
・次の具体目標
・総合点を入力中に自動計算
・試合保存時に選手記録と評価をまとめて保存
・既存試合を編集すると、保存済み評価を自動表示
・選手詳細の「試合評価」タブ、評価推移グラフ、AIアドバイスと連動
・Ver.8.1の軽量化を維持

Supabase
Ver.9.0のSQLを実行済みなら、追加SQLは不要です。

導入方法
1. ZIPを解凍
2. 中身をGitHubへ上書きアップロード
3. Commit changes
4. GitHub Pages反映後、Safariを再読み込み
5. 「試合入力」または試合一覧の「編集」を開く
6. 出場選手にチェック
7. 下の「試合評価・コーチコメント」を入力
8. 「試合を保存」を押す
9. 選手 → 詳細 → 試合評価 で履歴を確認
