# トラブル対応

## AIメニューが出ない
- GitHubの一番上にある`index.html`が新しいファイルか確認します。
- Safariでページを長押し再読み込み、または履歴とWebサイトデータを消去します。

## 接続確認が失敗する
- Docker Desktopが起動しているか確認します。
- `docker compose up --build`の画面にエラーがないか確認します。
- `http://localhost:8000/health`が開けるか確認します。

## AIが503になる
- `.env`の`OPENAI_API_KEY`が未設定です。
- `.env.example`ではなく`.env`という名前になっているか確認します。

## GitHub Pagesでは自分以外AIが動かない
- localhostはその端末だけの住所です。公開AIサーバーURLが必要です。
