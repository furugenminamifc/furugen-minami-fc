古堅南FC Ver.7.1 選手詳細画面 完全版

追加した機能
・選手一覧から「詳細」を開ける
・選手写真、基本情報、通算成績を1画面表示
・生年月日、利き足、身長、体重
・強み、次の成長目標
・疲労度、調子、コーチメモ
・保護者氏名、電話、メール、緊急連絡先
・最近の出場試合一覧
・選手詳細からAI育成評価を作成
・保護者・緊急連絡情報は管理者・コーチだけ取得可能

導入順
1. Supabase SQL Editorで「Ver7.1_選手詳細画面追加設定.sql」を1回実行
2. このフォルダの中身をGitHubへ上書きアップロード
3. GitHub Pages反映後、Safariで再読み込み
4. 「選手」→「詳細」で確認

重要
SQLを実行する前にGitHubだけ更新すると、新項目の保存時にエラーになります。
必ずSQLを先に実行してください。
