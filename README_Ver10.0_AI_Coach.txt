古堅南FC AI Coach Ver.10.0

Ver.9.5までの選手管理・試合記録・評価・MVP・AIコメント機能を維持し、
指導に必要な分析機能を1画面へまとめた「AIコーチングセンター」を追加しました。

追加機能
・AI試合診断
・スタメンおよび交代案
・次回練習メニュー
・選手育成診断
・動画URL／タイムスタンプメモ分析
・年間・大会分析
・選手数、試合数、得点、総出場時間をダッシュボード表示
・既存のAI画面へ分析材料を自動セット
・iPhone、iPad、Mac対応
・Ver.8.1以降の軽量化設計を維持

重要
Ver.10.0の動画分析は、動画URLとコーチが入力したタイムスタンプ・場面メモを使う方式です。
映像ファイル自体をコンピュータビジョンで自動認識する機能ではありません。
動画そのものの自動追跡・ヒートマップ・自動切り抜きには、別途動画処理サーバーと処理費用が必要です。

Supabase
Ver.9.0のSQLを実行済みなら追加SQLは不要です。

使い方
1. ZIPを解凍してGitHubへ上書きアップロード
2. GitHub Pages反映後にSafariを再読み込み
3. 上部メニューの「AI Coach」を開く
4. 使用する診断を選び、ボタンを押す
5. AI画面にセットされた内容を確認して送信
6. AI回答は指導者が確認・修正して利用

安全上の注意
AIの提案は参考案です。
体調、ケガ、本人の気持ち、当日の状況を優先し、最終判断は指導者が行ってください。
