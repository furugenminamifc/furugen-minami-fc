# 古堅南FC Ver.7.0 完全版

## 追加した5機能
1. AIスタメン自動提案
2. 出場時間・疲労度を考慮したAI交代提案
3. 試合終了後のAI試合レポート
4. 保護者向け連絡文のワンタップ生成
5. 年間成績・ランキングAI分析

## 導入順序
1. SupabaseのSQL Editorで `Ver7追加設定.sql` を1回だけ実行します。
2. このフォルダの中身をGitHubリポジトリの一番上へ、フォルダ構成を保って上書きアップロードします。
3. GitHub Pagesの反映を1〜3分待ちます。
4. RenderはGitHub更新を検知して自動デプロイします。RenderのEventsでLiveを確認します。
5. Safariで古堅南FCアプリを開き、再読み込みします。
6. 上部の「🚀 Ver.7 AI分析」を開き、AI接続確認→各機能をテストします。

## 保存について
- `Ver7追加設定.sql` 実行後は、コーチ・管理者が作成したAI案をSupabaseへ共有保存できます。
- SQL未実行時でもAI生成は使え、保存はその端末内のlocalStorageへ退避されます。
