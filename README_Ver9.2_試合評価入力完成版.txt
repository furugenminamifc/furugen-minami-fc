古堅南FC Ver.9.2 試合評価入力完成版

改善内容
・出場選手だけ／全選手表示の切り替え
・評価カードを「すべて開く」「すべて閉じる」
・選手写真、学年、ポジション、出場状態を表示
・8項目を星付き5段階で入力
・総合点をリアルタイム計算
・良かった点、改善点、次の目標を横並び表示
・前向きなコーチコメント例を自動入力
・各選手の評価からAIアドバイス画面へワンタップ連携
・試合保存時に選手記録と評価をまとめて保存
・選手詳細の試合評価履歴、グラフと連動
・Ver.8.1以降の軽量化設計を維持

Supabase
Ver.9.0のSQLを実行済みなら追加SQLは不要です。

使い方
1. 試合入力または試合編集を開く
2. 出場選手へチェック
3. 画面下の「試合評価・コーチコメント」を開く
4. 星評価とコメントを入力
5. 必要に応じて「前向きコメント例」または「AIアドバイス案」を使用
6. 試合を保存
7. 選手詳細 → 試合評価で履歴を確認
