古堅南FC Ver.9.0 試合評価・コーチコメント・AIアドバイス 完全版

追加機能
・選手詳細に「試合評価」タブを追加
・試合ごとに8項目を5段階評価
  攻撃、守備、パス、ドリブル、シュート、判断力、運動量、コミュニケーション
・良かったところ
・改善したいところ
・次の具体目標
・項目別平均点
・直近10試合の評価推移グラフ
・評価履歴
・試合評価からAIアドバイスをワンタップ生成
・選手全体のAI育成評価にも最近の試合評価を反映
・管理者、コーチのみ閲覧・編集可能
・Ver.8.1の軽量化設計を維持し、選手詳細を開いた時だけ評価データを取得

導入順
1. Supabase SQL Editorで「Ver9.0_試合評価_AIアドバイス追加設定.sql」を1回実行
2. このフォルダの中身をGitHubへ上書きアップロード
3. Commit changes
4. GitHub Pages反映後、Safariで再読み込み
5. 選手 → 詳細 → 試合評価 を開く
6. 試合を選び、評価とコメントを保存
7. AIアドバイスを押して内容を確認

注意
AIの回答は指導の参考案です。本人の気持ちや当日の状況を優先し、
最終的な伝え方は指導者が確認してください。
