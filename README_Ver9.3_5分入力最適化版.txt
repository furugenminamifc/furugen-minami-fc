古堅南FC Ver.9.3 5分入力最適化版

目標
コーチが試合終了後、約5分で出場選手の評価入力を終えられる画面に改善しました。

追加・改善内容
・操作パネルを評価欄上部に固定表示
・「全選手を表示」を見やすいスイッチ化
・すべて開く／すべて閉じるを整理
・表示中の全員を評価3・4へ一括設定
・出場選手だけを評価3・4へ一括設定
・表示中のコメントをまとめて空にする
・評価対象人数とコメント入力人数を表示
・コメント入力進捗バー
・入力欄とボタンを大きくし、Mac・iPad・iPhoneで操作しやすく調整
・評価カードは出場選手のみ自動で開く
・Ver.9.2までのAIアドバイス、コメント例、保存、履歴、グラフ機能を維持

おすすめ入力手順
1. 選手記録で出場選手にチェック
2. 「出場選手 3」を押す
3. 良かった選手だけ4・5に変更
4. 必要な選手へコメントを入力
5. 「前向きコメント例」や「AIアドバイス案」を必要な時だけ使用
6. 試合を保存

Supabase
Ver.9.0のSQLを実行済みなら、Ver.9.3の追加SQLは不要です。
