古堅南FC Ver.8.1 軽量化・高速化版

今回の改善
・選手一覧を20人ずつ表示
・検索や状態変更時は自動で1ページ目へ戻る
・選手写真を遅延読み込み
・メディカル、成長記録、技術評価、保護者情報を全選手分まとめて取得しない
・選手詳細を開いた時、その選手のカルテだけ取得
・選手詳細データを5分間キャッシュ
・カルテ保存後にアプリ全体を再読み込みしない
・AIレポート、動画メモ、AI計画は最新100件まで取得
・不要な全画面Realtime再読み込みを削減
・既存のVer.8.0機能は維持

Supabase
追加SQLは不要です。
Ver.8.0のSQLを実行済みなら、そのまま使用できます。

導入方法
1. ZIPを解凍
2. 中身をGitHubへ上書きアップロード
3. Commit changes
4. GitHub Pagesの反映を待つ
5. Safariで再読み込み
6. 「選手」で20人ずつ表示されることを確認
7. 「詳細」を開いてメディカル・技術評価・成長カルテを確認

期待できる効果
・初回読み込みデータ量の削減
・選手詳細を開くまで個人カルテを取得しない
・100人以上の選手がいても一覧表示が軽くなる
・保存操作後の待ち時間を短縮
